MODIFICATION NOTICE

This archive contains a course subset and transformed representations of
the upstream data. It is not the complete upstream training dataset.

raw/train.txt contains only the first 25,000,000 upstream bytes.
raw/valid.txt contains the complete upstream V2 GPT-4 validation file.

The prepared JSONL files are changed representations. The course discards
the incomplete training tail, requires valid UTF-8, rejects replacement
characters, collapses whitespace, removes exact normalized duplicates,
and selects validation/test stories using a seed-42 shuffle.

The tokenized BIN files are changed representations of those prepared
stories, encoded using the accompanying 4,096-token byte-level BPE
tokenizer. An end-of-text token with ID 0 follows each story. The tokenizer
was fitted only on the course training stories.

The manifests identify the exact source files, transformation scripts,
environments, counts, and hashes. Companion .NOTICE.txt files identify
which transformations apply to individual data files.

The data, including these changed data representations, is distributed
under the unmodified CDLA-Sharing-1.0 terms. No course payment or code
terms add restrictions to those data rights.

Course preparation: You Know Its Me Studios course materials.
The course source code and the third-party dataset are separate materials.
